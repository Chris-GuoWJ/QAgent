# 从腔谱之后到单比特验收

依据现场《单比特校准清单.txt》。起点是人工已用 VNA 校准放大链和谐振腔，交接给测控板；VNA 腔谱通过并不能证明 ADC 时序、读出或门已经可用。下表给出新比特的依赖顺序。已有经过验证、与同一比特和当前工作点匹配的证据时，可从相应阶段接续。早期参数用于建立可测性，后面还要复核。

| 顺序 | 操作与验收依据 | QuantumX 方法索引 |
| --- | --- | --- |
| 1. 测控板读出交接 | 用 VNA 低功率腔频给 `readoutFreq` 初值，预设 `readoutLen`。在板上复扫局部腔谱，采完整返回波形，确定 ADC 到达时刻、采集延时和初始积分窗。粗选 `readoutPower`、`readoutAmp`，确认响应稳定且 ADC 不饱和。初次优先在工作偏置直接读出；只有确有需要才用保守读出 Z 并验证到达和稳定时间，记为临时设置。 | `sParameter`、`calReadoutTiming`、`calInitialReadout` |
| 2. 找 f10 | 使用独立于 `piLen` 的长 XY 谱驱动（约 10 μs 是清单中的参考量级），按已验证的幅度范围扫多个档位，比较匹配时窗有/无驱动的平均复 IQ。需要可辨认、可重复且被扫宽覆盖的谱峰；此步不要求两态分类中心，也不要求已知 π。 | `spectroscopy` |
| 3. 静态磁通谱与候选工作点 | 在不同安全 `Zbias` 上等待稳定后重复找频，拟合 f10–Zbias 映射，得到甜点、周期和可用偏置区间；初次用静态偏置避免未校准的快速 Z 拖尾。若识别到 0→2 双光子峰，实际驱动频率是 f20/2，非谐性为 `2 × (f20/2 − f10)`；若没看到，可在获得粗 π 后再测 f21。记录采用的工作偏置，通常以甜点为候选。 | `calFluxSpectrum`、`calAnharmonicity` |
| 4. 粗 π | 在选定工作点用可用的 f10，固定门包络、`piLen`（约 20 ns 是候选示例）和频率，扫 `piAmp`。可用平均 IQ 投影做幅度 Rabi，不必先有中心。确认从零驱动出发的首个完整翻转峰、对比度和拟合，取得可用的粗 π。 | `pituner` |
| 5. 初始 IQ、粗 T1 与恢复 | 用不加 π / 加粗 π 制备近似 0/1，按匹配时窗采集单次 IQ。完整流程交替分块并用留出样本验证分类；CLI v1 的两态采集固定每态一组，报告时说明实际方式。用可用中心粗测 T1，再扫复位等待，验证起始态稳定。这里的两态分离包含制备误差，中心和粗 T1 不能当成最终验收。 | `calc_readout_centers`、`calT1`、`calRecovery` |
| 6. XY–Z 对时 | 用粗 π 配合经验证的短 Z 方波；频移须可辨认，Z-only 不应有明显额外转移。扫相对时间，用激发受抑制的重叠区拟合延时补偿。`z_amp` 和 `z_duration_s` 由现场明确提供；不要猜测。涉及读出 Z 的时序改动后，先复核读出中心再继续。 | `calXYZDelay` |
| 7. 粗 π/2 与轴相位 | 同包络、同门长可用 `piAmp/2` 作候选起点。检查两个同向 π/2 的翻转和分析相位扫描，确认 X、Y 轴及正负号。取得可用的粗 π/2 后才进入首次 Ramsey。 | `calPiHalf` |
| 8. 首轮 Ramsey 精频 | 已有参考 f10、可用粗 π/2 和读出中心后，测带符号残余失谐，精调 f10 并复查粗 π、π/2；扫轴须能解析参考条纹。Ramsey 不能代替宽谱找频。 | `freqtuner` |
| 9. Z 拖尾与预补偿 | 用经过对时的 Z 路径施加长方波，以撤除时刻为零点扫第一枚 π/2 的时刻；固定较晚的分析时刻，兼顾拖尾小和相干对比度。每点配对无 Z 参考，扣除自然相位演化；用已测静态映射的可逆分支拟合拖尾，建立预补偿，并比较补偿前后实测结果。 | `calZDistortion` |
| 10. 条件性损失排查 | 需要验证候选工作点或 Z 转移路径时，用粗 π 和已验证的 Z 路径测 detune T1 / 频率—损失图，找交换、缺陷和损失区。若因此换工作点，回查 f10、π、π/2 和初始读出，评估 Z 映射及后续结果是否还适用。 | `calDetuneT1` |
| 11. 精调读出与清空 | 从近似 0/1 出发，沿相同读出 Z 路径优化 `readoutZAmp`、`readoutFreq`、`readoutPower`、`readoutAmp`、`readoutLen` 和积分窗；Z 改变时可和频率局部联合扫描。比较留出集区分度，检查转移损失、读出弛豫和高能级泄漏，再验证腔清空和恢复等待，确认残余光子不影响后续门。 | `calReadout`、`readoutAmpFid`、`readoutZpaFid`、`calReadoutPath`、`calCavityClear`、`calRecovery` |
| 12. 转角、DRAG 与交替复查 | 用改善后的读出检查残余失谐，用重复同向旋转放大有符号的 π、π/2 转角误差；小范围 Rabi 只细化初值。固定 f10、门长和幅度，分别扫 `Xπ/2 → (Xπ → −Xπ)^N → Xπ/2`、`Xπ/2 → (Yπ → −Yπ)^N → Xπ/2` 的 `alphaDRAG`，比较两轴和不同 N 的高 P(1) 一致区，两序列理想终态均为 1。复查泄漏、π/π/2 转角；小范围交替检查 f10、两种幅度和 alpha，直到残差达标。门更新后检查残余失谐，只有漂移或换点等需要时才重做完整 Ramsey。 | `freqtuner`、`calRotationAmplitude`、`calDRAG`、`calLeakage`、`calTuneGates` |
| 13. 最终表征与读出矩阵 | 在最终工作点重新测 T1 与 Hahn Echo（π/2 → τ/2 → π → τ/2 → 分析 π/2）。重新采两态单次 IQ，更新最终中心、分类器、读出保真度与指派矩阵；保存原始计数和方向 `M[measured,prepared]`，使 `p_measured = M @ p_prepared`。改变制备或读出条件后复核矩阵；要定量验证 2 态泄漏时须有经过验证的三态制备/分类。 | `calT1`、`calT2Echo`、`calc_readout_centers`、`calReadoutMatrix`；需要三态时参考 `calPi21` |
| 14. 独立验收和归档 | 用独立批次做单比特参考 RB，按需要做重点门的交错 RB，检查泄漏和重复测量稳定性。按现场验收阈值判断；独立验收通过才可称单比特校准完成。保存工作偏置、f10、读出与时序/Z 补偿、π/π/2、门长、包络、门间隔、DRAG 及对应数据和验收证据。多比特同时运行再加串扰和同时 RB。 | `sqRbClifford`、`calRBAcceptance`、`snapshot`、`save_result`；多比特参考 `calCrosstalk` |

## 怎么判断下一步

- 问完整顺序时，按物理依赖说明全流程，区分初始、精调、最终验收。运行时的 `registered_experiments` 只决定谁来做：方法未注册时标为“需现场完成或补接口”，说明交接证据；不要删除它或用下游实验代替它。
- 问当前比特的进度或下一步时，查询实际实验记录和需要的结果；结合用户确认的现场交接证据，说明已验证的阶段、最早未满足的前置、可执行的下一步或要补的证据。`completed` 仅表示执行结束，`quality.valid`、`quality.accepted`、独立验收各有不同含义；表征实验可以有效却没有可传递的候选。记录缺失是未证实，不能推断现场从未做过。阈值取现场约定和实际工具结果。
- 若多次找频的峰不稳定、质量未通过，且没有现场验证的 f10 和可用粗 π，先检查同工作点的局部腔谱、原始 ADC 波形/积分窗、饱和与漂移、参考和驱动平均 IQ 差、工作偏置、XY 路由和扫描范围。可将已验证的历史工作点作为条件性证据；不能把失败峰值当成 f10，或为节省预算先做两态中心，再拿分离度解释找频失败。只有已有可用制备时，读出中心才可用于这类补测。
- 继承合格候选时，核对同一比特、工作点、读出/脉冲条件与执行器，使用 `reference_experiment_id` 明确引用合格结果，并核对实际生效输入。CLI 一次只显式引用一个候选，连续更新应保持正确的继承链；不会自动汇总历史记录、写回原始配置，也不能拿过时的中心证明新条件可用。
- 用 `get_calibration_skill` 查单个方法的参数、单位和注意事项，用实际 `describe`/预检及会话余量判断能否提交。清单中的示例量级不能直接当设备参数。规划和排障不启动硬件；用户明确要求时仍逐项运行，每条指令至多新建一个实验。
